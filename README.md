# BUCKET-R2

A bucket with opinions. Tool for **show**.

Grayscale eye. Speaker drum. Guitar in the room. Language only on an earned hit.

```
see → feel the beat → hit → hear → say a word → see
```

Each bar steps the HEX-SPLIT fifths walk (`clock.py`). Mouth says the gray sticker only if the drum hit. Guitar stub on Express. Compress bars listen.

Clock law lives in [HEX-SPLIT](https://github.com/One-Wave-Universe/HEX-SPLIT) (`clock.json`, `SYNC.md`). Copy `clock.json` beside `clock.py` to share one payload. Hold = no speak.

## Run the dry loop (no hardware)

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python loop.py
python loop.py --beats 24
```

Replace stubs in `senses.py` when a camera and speaker exist.

## Rule

Language is learned on the beat. If it cannot drum, it does not talk. Show without a stamp is illegal.
